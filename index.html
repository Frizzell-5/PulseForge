User guide

1 · Quick start (60 seconds)

  1. Click Launch Studio. A demo song is already loaded.
  2. Press Space (or ▶) to play. Click SONG to hear the whole arrangement, or PAT to loop one pattern.
  3. In the Channel Rack, click squares to switch drum hits on and off. Drag across them to paint, and right-click to erase.
  4. Click a channel's name, then draw notes in the Piano Roll. Out of ideas? Press ✨ Melody, ✨ Chords or ✨ Groove.
  5. Paint your patterns into the Playlist to build a full song.
  6. Add effects in the Mixer, then use File → Export WAV.

2 · The dynamic workspace

Every panel (Browser, Playlist, Channel Rack, Piano Roll and Mixer) is a floating window:

  • Drag a window by its title bar. It snaps to the edges of other windows.
  • Resize it from the bottom-right corner. Double-click the title to maximize, and click ✕ to hide.
  • Switch between ready-made layouts in View: Studio, Beat making, Compose, Arrange and Mixing.
  • Toggle panels with F5–F9. Your layout is remembered.
  • On phones, panels become full-screen tabs along the bottom: Rack, Piano, Song, Mixer and Browse.

3 · How it all fits together

Channels

Your instruments: drums, synths or samples. Double-click one to edit its sound. The number next to it is the mixer track it plays through.

Patterns

Short clips of notes for all channels. The rack's squares and the piano roll edit the same notes. Switch patterns with the selector at the top.

Playlist

Where patterns are placed over time to make a song. PAT mode loops one pattern; SONG mode plays the playlist. Click the ruler to play from any bar.

Mixer

Each track has volume, pan, mute/solo and an effects chain, and everything flows into the Master. Click a track to edit its effects.

4 · Making your first beat

  1. File → New project gives you a kick, snare, hat and synth.
  2. Kick on steps 1, 5, 9 and 13; snare on 5 and 13; hats on every other step. Press Space.
  3. Select the synth, pick a Scale in the piano roll, turn on 🔒 Lock, and draw a bassline. Every note stays in key.
  4. Click ＋ next to the pattern selector to make Pattern 2 for a melody. Try ✨ Melody.
  5. In the Playlist, select each pattern and paint it onto a track. Press SONG, then ▶.
  6. In the Mixer, add Reverb to the melody track and a Compressor to the drums.
  7. Scroll the mouse wheel over a lit step to make it quieter or louder. Hats sound more human that way.

6 · Installing on each device

🪟 Windows

Download the .exe above and run it. If SmartScreen appears, click More info → Run anyway (the app isn't code-signed yet). You can also open the studio in Chrome or Edge and click the install icon ⊕ in the address bar.

⌘ macOS

Download the .dmg, open it and drag PulseForge into Applications. The first time, right-click the app → Open → Open, because it isn't notarized by Apple yet. Or install from Chrome or Edge with the ⊕ icon.

🐧 Linux

AppImage: run chmod +x PulseForge-Studio-Linux.AppImage, then double-click it. Debian/Ubuntu: sudo apt install ./PulseForge-Studio-Linux.deb.

📱 iPhone / iPad

Open this page in Safari → tap Share → Add to Home Screen → Add. Launch it from the new icon. Switch off silent mode to hear sound.

🤖 Android

In Chrome, tap Install app above, or ⋮ → Install app. It appears in your app drawer.

💻 Chromebook

Click Install app above, or the ⊕ icon in Chrome's address bar.

7 · Saving, exporting & your data

  • Your project autosaves in this browser or app as you work.
  • File → Save project file downloads a .pfproj file with your samples inside. Open it on any device with File → Open, or drag it into the window.
  • Export WAV renders the song in SONG mode, or the current pattern in PAT mode. Export MIDI sends a pattern to any other music app.
  • Drag audio files anywhere onto the studio to turn them into sampler instruments.
  • There are no accounts, servers or tracking. Your music never leaves your device unless you share it.

FAQ

Is it really free?

Yes. PulseForge is open source under the MIT license. Every feature is free for everyone, with no trial or upgrade.

Does it work offline?

Yes. Once you've installed it (or opened it once), it works without an internet connection.

I don't hear any sound.

Click anywhere in the studio first, because browsers only allow audio after you interact with the page. On iPhone, switch off silent mode. Also check that the channel and mixer track aren't muted.

Can I use my MIDI keyboard?

Yes, in Chrome, Edge and the desktop app. Plug it in, select a channel and play. Press ● to record while the pattern plays.

Will my projects move between devices?

Use File → Save project file and open that file on the other device. Samples are included in the file.

Is this affiliated with FL Studio?

No. PulseForge is an independent project, not affiliated with Image-Line or FL Studio.
